How to read a proposal

Same entityA spelling or legal-form variant of the group's own name (for example "Areion Assets Management Private Limited").
Fund ofA fund or sub-fund run by the group. Names that differ only by Ltd, Inc, Fund or Trust are already treated as equal by the database; this is the step beyond that.
Vehicle ofA holding vehicle, for example the "SVF ..." companies for SoftBank.
RelatedThe name starts with the group's name (a subsidiary, branch or affiliate). Check that the brand really means one owner: "Prudential" is used by unrelated companies.
Held via (off by default)The name starts with a custodian or trustee and says "Re:", "as trustee" or "on behalf of". The fund usually belongs to someone else, so it is excluded unless you include it.
